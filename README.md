# IT Academy — تأمين البنية التحتية للشبكات
عرض تدريبي تفاعلي باللغة العربية حول تأمين البنية التحتية للشبكات في عصر الأمن السيبراني.
## التشغيل على Replit
لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم خاص. افتح `index.html` في Preview، أو شغّل أي خادم ملفات ثابت:
```bash
python3 -m http.server 3000
```
ثم افتح رابط المعاينة الذي يوفره Replit.
## الملفات
- `index.html`: هيكل العرض ومحتوى الشرائح وملاحظات المتحدث.
- `style.css`: التصميم المتجاوب، الألوان، الرسوم التوضيحية، وتنسيق RTL.
- `script.js`: التنقل، التقدم، الاختصارات، الملاحظات، ملء الشاشة، والسحب على الجوال.
## التحكم
| الإجراء | الطريقة |
| --- | --- |
| الشريحة التالية | زر «التالي»، سهم اليمين، `Page Down`، المسافة أو `Enter` |
| الشريحة السابقة | زر «السابق»، سهم اليسار أو `Page Up` |
| البداية / النهاية | `Home` / `End` |
| ملاحظات المتحدث | زر الملاحظات أو `N` |
| ملء الشاشة | زر ملء الشاشة أو `F` |
| على الجوال | السحب يميناً أو يساراً |
## ملاحظات
- اتجاه العرض RTL ومصمم للعمل على الشاشات الكبيرة والجوال.
- خط Cairo يتم تحميله من Google Fonts مع خط بديل محلي في حال عدم توفر الاتصال.
- روابط المراجع في الشريحة الأخيرة تفتح في تبويب جديد.
- لا توجد قاعدة بيانات أو مفاتيح سرية أو اعتماد على إطار عمل؛ يمكن تعديل المحتوى مباشرة داخل `index.html`.
