# تأمين البنية التحتية للشبكات في عصر الأمن السيبراني
## IT Academy — عرض تدريبي تفاعلي

عرض تقديمي تفاعلي باللغة العربية (RTL) يغطي تأمين البنية التحتية للشبكات،
تأثير الأمن السيبراني على الموارد، والآثار الأمنية للأنظمة المتصلة (IoT و SCADA).

### ✨ المميزات
- واجهة عربية كاملة RTL بخط Cairo/Tajawal.
- 19 شريحة قابلة للتنقل (أزرار، لوحة مفاتيح، سحب باللمس).
- ملاحظات متحدث تفصيلية لكل شريحة.
- فهرس تفاعلي للتنقل السريع.
- تصميم متجاوب مع الجوال.
- سيناريو عملي شامل يجمع كل المفاهيم.
